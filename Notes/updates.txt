26-11-2025 Changes:
- moved all weapon profiles, including special & operative specific weapons, up to the common-weapons{} dict, now renamed to "weapons{}" dict since it contains the dictionary of all operative's weapons
- updated the operatives' weapon-options{} dicts' lists to include the keyword of their weapon, referred from the weapons{} dist
    + Initially a operative keyword specifier was added to the special/operative-specific weapon's profiles, but it was abandoned to 1. avoid re-complicating the data structure, and 2. those weapon profiles will only be referred if their weapon keyword is included within the operative, making those operative keyword redundant and could cause a loading-data error
    + "weapon-name" dict is moved to the parent-level of the dict, same level as the "profiles:{}" dict.
- weapons with only 1 profile in the shoot{} dict inside weapon{} dict have been added indo a profile:{ default: {} } nested dictionary, to conform to shooting{}weapon profiles with multiple profiles' structure. 
- melee weapons remain the same as before as none have more than 1 profile
- operative keywords have been changed to the same format as weapon keywords, with all lowercase and space between reduced with the "-" dashes
    + operative-selection{} dict's nested dictionary also has the keywords for operative selection limits changed so that it fits the keyword inside the listed operative's keyword list (for cross-checking limit and validity once loaded it)
    + operatives with no limits have had its value changed from 0 --> 99 --> null
- Weapon keyword have similarly been changed to conform to the datasheet's keyword structure as well.
    + Keywords remain the same structure as "this-keyword-here", but a space in between the keyword and number/integer is to display its modifier value
    + These keywords will be defined in a separate python file, which the game will use as reference and check for the weapon keyword, and modifier to apply it appropriately according to game rules.
    + Heavy (Dash Only) --> heavy-(dash-only) --> heavy
